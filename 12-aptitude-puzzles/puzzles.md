 Classic Puzzles

Tags: #aptitude #puzzles
Difficulty: Hard
Status: Learning

## Definition

Classic puzzles often involve edge cases, constraints, and hidden assumptions not immediately obvious from the wording.

## Why it matters / when to use

They test structured reasoning, calm thinking, and the ability to question assumptions.

## How it works

Read carefully, identify assumptions, try a small example, and build a model that matches all constraints.

## Code example

```ts
const total = 3;
const pairs = (total * (total - 1)) / 2;
console.log(pairs);
```

## Time and space complexity

Usually not relevant; reasoning quality matters more than code complexity.

## Common mistakes and pitfalls

- Overlooking hidden assumptions
- Jumping to a conclusion without validation
- Failing to simplify the problem before solving it

## Interview questions

### Q: What is the best way to approach a puzzle?
Model answer: Start by converting the problem into a smaller sample, identify the real rule, and then test the pattern before generalizing the solution.
