 Networking

Tags: #cs #networking
Difficulty: Medium
Status: Learning

## Definition

Networking is the study of how devices communicate over digital systems using protocols and addressing schemes.

## Why it matters / when to use

It explains APIs, distributed systems, and web communication in production systems.

## How it works

Protocols like TCP, UDP, IP, DNS, and HTTP define how requests and responses move between systems.

## Code example

```bash
curl https://example.com
```

## Time and space complexity

Networking is mostly about latency, throughput, and failure modes rather than Big O.

## Common mistakes and pitfalls

- Confusing HTTP and TCP
- Ignoring retries and timeout behavior
- Forgetting the role of DNS and load balancing

## Interview questions

### Q: Why do we need load balancers?
Model answer: They distribute traffic, reduce the impact of a single server failure, and improve availability and throughput.
