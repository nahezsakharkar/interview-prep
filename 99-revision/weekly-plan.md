# 🚀 Sprint to Ready: 4-Week High-Intensity Plan

This plan is designed to bridge the gap between "knowing the patterns" and "interview ready" for SDE-II/III roles.

## 📅 Daily Cadence
| Time Block | Focus | Goal | Resource |
| :--- | :--- | :--- | :--- |
| **Morning** (08:00-12:00) | **DSA Volume** | 1h Pattern Review $\rightarrow$ 3h Problem Volume | `01-dsa/leetcode-roadmap.md` |
| **Afternoon** (13:00-17:00) | **CS Fundamentals** | Deep dive into Internals (DB, OS, Network) | `05-databases/`, `06-os/` |
| **Evening** (19:00-22:00) | **System Design & Behavioral** | 1 HLD $\rightarrow$ 1 LLD $\rightarrow$ 1 STAR Story | `14-resume-deep-dive/` |

---

## 🗓️ Weekly Roadmap

### Week 1: Foundations & Linear Structures
- **DSA**: Arrays, Hashing, Two Pointers, Sliding Window. 
  - *Target*: Complete all "Easy" and 50% of "Medium" in these categories.
- **CS Fundamentals**: DB Internals (B-Trees, WAL, Buffer Pool), OS Basics (Process vs Thread).
- **Design/Behavioral**: Load Balancing, Caching. Behavioral: "Tell me about yourself" & Project 1 deep dive.

### Week 2: Hierarchies & Search
- **DSA**: Stack, Binary Search, Linked Lists, Trees, BFS/DFS.
  - *Target*: Focus on recursive patterns and boundary conditions.
- **CS Fundamentals**: Concurrency (Locks, Semaphores, Deadlocks), DB Indexing (Clustered vs Non-Clustered).
- **Design/Behavioral**: API Gateway, Rate Limiting. Behavioral: Project 2 deep dive.

### Week 3: Advanced Optimization
- **DSA**: Heap, Backtracking, Graphs (Topo Sort, Dijkstra).
  - *Target*: Implement Dijkstra and Topo Sort from scratch without hints.
- **CS Fundamentals**: OS Memory (Virtual Memory, Paging), NoSQL Internals (LSM Trees).
- **Design/Behavioral**: Distributed Systems (CAP, PACELC, Consensus). Behavioral: Project 3 deep dive.

### Week 4: Mock Mode & Polish
- **DSA**: Dynamic Programming, Mixed Hard patterns, Random LC Contests.
  - *Target*: 2 Mock assessments per day.
- **CS Fundamentals**: Review `99-revision/mistakes-log.md`, Final polish on DB/OS.
- **Design/Behavioral**: End-to-end System Design mocks, STAR method drills for all resume projects.

- [ ] 5+ polished STAR stories mapped to resume projects.
