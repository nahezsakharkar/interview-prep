# Interview Prep Knowledge Base

## Purpose

This repository is a personal, Markdown-only knowledge base for preparing for software engineering interviews. It combines concise concept notes, problem-solving practice, reusable templates, and a revision log. There is no build step: browse the files in VS Code or GitHub.

## How to use this repo

1. Start with a target role and choose the relevant sections below.
2. Read a note, then explain the concept or solve a problem without looking.
3. Record mistakes and questions in [99-revision/mistakes-log.md](99-revision/mistakes-log.md).
4. Use the templates in [templates](templates) when adding notes; link related topics with relative Markdown links.
5. Revisit notes on the schedule in [How I revise](#how-i-revise).

## How I revise

### Daily

- Pick one focused topic or a small set of coding problems.
- Recall the idea before rereading; then solve or explain it from memory.
- Log mistakes, unclear assumptions, and follow-up practice in [99-revision/mistakes-log.md](99-revision/mistakes-log.md).

### Weekly

- Review the week's mistakes and revisit due items.
- Practice a mix of coding, system design, and behavioral questions relevant to the target role.
- Update the [weekly plan](99-revision/weekly-plan.md) and the checklist above.

### Pre-interview

- Prioritize high-yield notes and mistakes due for review; avoid trying to learn every topic at once.
- Do a timed coding round and one concise system-design walkthrough.
- Rehearse a few STAR stories and prepare questions for the interviewer.
- Confirm the interview format, logistics, and any role-specific areas to review.
